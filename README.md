# Infosys Internship Project – Threat Incident Analytics

## Project Overview

This project was developed as part of an Infosys Virtual Internship using Microsoft Power BI. The project focuses on analyzing security incidents, threat severity, geographical risk, incident trends, response performance, and predictive risk intelligence.

The solution transforms raw security incident data into interactive dashboards that help identify major threats, high-risk locations, response patterns, and emerging risks.

## Objectives

* Analyze security incidents and threat categories
* Identify critical and high-severity incidents
* Analyze geographical distribution of security threats
* Study incident trends across time
* Evaluate incident response and resolution performance
* Identify high-risk cities and threat categories
* Develop predictive and executive-level risk insights
* Provide data-driven recommendations for security operations

## Tools and Technologies

* Microsoft Power BI
* Power Query
* DAX
* Microsoft Excel / CSV
* Data Cleaning and Transformation
* Data Visualization
* Geospatial Analysis
* Predictive Risk Analysis

## Datasets

The project uses three primary datasets:

* `Incidents_1500.csv` – Security incident information
* `Locations_1500.csv` – Location and geographical information
* `Responses_1500.csv` – Incident response information

## Project Milestones

### Milestone 1 – Security Threat Analysis

The first milestone establishes the baseline incident analytics dashboard.

Key analysis includes:

* Total incidents
* Critical incidents
* Threat categories
* Severity distribution
* Monthly incident trends
* Incident locations
* Response status
* Impact distribution
* Average response time

### Milestone 2 – Threat Classification and Geospatial Intelligence

The second milestone extends the analysis into threat classification and geographical intelligence.

Key analysis includes:

* City risk analysis
* State-wise threat hotspots
* Critical incident trends
* Escalation rate by threat category
* Top-risk cities
* Response time by city
* Threat concentration

### Milestone 3 – Temporal and Incident Response Analytics

The third milestone focuses on when incidents occur and how efficiently they are handled.

#### Temporal Incident Analytics

Analysis includes:

* Monthly incident trends
* Incidents by day of week
* Seasonal incident distribution
* Threat category contribution
* Severity distribution
* Escalated incidents

#### Incident Response Analytics

Analysis includes:

* Average response time by team
* Response efficiency
* Average resolution time by severity
* Response status
* Response workload by team
* Responses by state
* Impact distribution

## Key Business Insights

1. Security incidents are distributed across multiple threat categories rather than being concentrated in a single threat type.
2. Several cities consistently show higher incident volume and severity, requiring greater security attention.
3. Incident response is relatively fast, but complete resolution takes considerably longer.
4. Incident activity follows identifiable temporal patterns, allowing organizations to plan staffing around peak periods.
5. Predictive analysis provides additional insight into potential future security risks.

## Business Recommendations

* Prioritize security resources in high-risk cities.
* Improve response and resolution procedures for high-escalation threats.
* Increase staffing during identified peak incident periods.
* Standardize incident-resolution workflows across response teams.
* Increase preventive controls for emerging high-risk threat categories.
* Establish regional monitoring for identified high-risk zones.
